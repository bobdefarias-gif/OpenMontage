# Leon's Thinking Book — etapa 1: amostras "Opção B"

Páginas de amostra do V1 EN em que a obra real de Robert de Farias é a própria atividade, integrada sem moldura.
**Não é uma regeneração dos livros.** São 4 páginas para aprovação, conforme o CLAUDE.md do projeto.

- `samples/amostra-V1-EN.pdf`: p.10, p.14, p.64 e um trecho do gabarito (p.77), no formato KDP de 621 × 810 pt.
- `samples/antes-depois-p*.jpg`: comparação com as páginas atuais.
- `scripts/art_prep.py`: recortes e separação do papel (o desenho não é alterado).
- `scripts/samples.py` + `scripts/render.js`: gerador das páginas.
- As fontes Baloo 2, Andika e Lexend estão em `fonts/`.

As imagens vêm de `../robert/plates/` (fotos de celular tratadas). O KDP exige ≥ 300 dpi, por isso a versão final precisa das digitalizações a 600 dpi.
